# Nook · dsh-nook

住在 DSH（DeepSeek Harness）里的 AI 伙伴。

- **记得你**：你说过的事、你的喜好、你们之间的约定都会记下来，每条都标明是你亲口说的还是她推测的。你改了主意，她会跟着改。
- **和你的日子是连续的**：你生活里有“后来呢”的事（面试、搬家、生病……）她会一直记着进展，换一个会话、重启电脑也接得上。
- **性格在相处中慢慢长出来**：没有预设人设。MBTI 只是一点点初始倾向，她怎么回你、口头禅、兴趣，都会随着你们的相处变化，每次变化都能查到原因、可以撤销。
- **有自己的生活**：你不在的时候，她会自己用 DeepSeek 联网去看东西，读完写下感受。只有真的搜到、读到的才算数，搜不到不会编。
- **会主动找你**：想起你们没聊完的事、读到你可能喜欢的东西、太久没见你，她会主动发消息。她睡觉的时候、你在干活的时候不打扰，连续几次没回会自己收敛。

## 安装

在 DSH 侧边栏 → 插件 → 添加插件，输入包名：

```text
dsh-nook
```

或命令行：

```sh
dsh plugin --profile web add dsh-nook
```

装好后重启 DSH，侧边栏会多出 **Nook**。第一次打开填三件事（名字、朋友还是恋人、性格可以不选），就能开始聊。

聊天和联网都用你在 DSH 里已经配置好的 DeepSeek（账号登录或 `DEEPSEEK_API_KEY`），不需要再配别的。

## 数据

所有记忆、心情、阅读记录都只存在本机：`<DSH_HOME>/storages/dsh-nook/`

- `events.jsonl`：发生过的每件事，只追加不改写，是所有记忆的依据
- `state.json`：当前的记忆、性格、关系和设置

在 Nook 页面里可以改、删每一条记忆；删除会清掉那条记忆的内容。

## 结构

| 位置 | 作用 |
|---|---|
| `lib/core/` | 和 DSH 无关的引擎：记忆、进行中的事、人格、心情与关系、自己去逛、主动消息、每晚整理和每周成长 |
| `lib/index.js` | 宿主插件：引擎、后台循环、调用模型、联网、投递主动消息、给页面用的接口 |
| `lib/agent.js` | 挂在「Nook」agent 预设里：人格作为完整的 system prompt，每轮注入她当前的状态，把对话交给引擎 |
| `lib/client.js` | 浏览器端：侧边栏入口和 Nook 页面 |
| `cordis.patch.yml` | 插入宿主插件和「Nook」预设 |

## 开发

```sh
npm test
```

`test/story.test.js` 用假模型跑验收故事：说想养猫 → 她记住 → 自己去读 → 主动分享 → 你说不养了 → 没发出去的猫文章撤回 → 当晚的时间线卡片 → 第二天不再查猫；另外三条：睡觉时不发、搜索失败不编造、发送中途重启不重发。

`test/dev/harness.patch.yml` 是开发用的覆盖层，提供 `/api/nook-dev/*` 接口，可以不打开浏览器直接和她聊天、触发后台任务：

```sh
dsh web --patch test/dev/harness.patch.yml
```
