# 设计语言

拟人化插件的界面只做一件事：让人感觉到“她记得我、她在这里”。下面这些规则写在 `lib/client.js` 的样式里，改界面之前先读这里。

## 原则

1. **内容是主角。** 她记得什么、你们发生了什么，就是页面本身。标题、标签、边框都往后退。
2. **一屏一个焦点。** 记忆页是「今天」那张卡片，状态页是她此刻的一句话。别的东西都不和它抢。
3. **温暖靠材质，不靠堆砌。** 纸张、淡水彩、柔和的光，只出现在少数地方。
4. **不写说明书。** 页面上没有解释性的提示文字。空状态只说“还没有”。

## 字号

只用五级，不新增：

| 用途 | 字号 | 字重 | 墨色 |
|---|---|---|---|
| 她的名字 | 30 | 600 | ink1 |
| 焦点内容（今天的卡片标题、此刻的心情） | 20 | 600 | ink1 |
| 正文、列表 | 15 | 400 / 500 | ink1 |
| 区块标题 | 15 | 600 | ink2 |
| 日期、辅助信息 | 12.5 | 400 | ink3 |

区块标题和正文一样大，只靠字重和灰度区分——标题是路标，不是主角。

时间线卡片和她写的感受用宋体（`--serif`），像手写的本子；其余用系统黑体。

## 颜色

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink1` | #24211d | 正文 |
| `--ink2` | #5c5750 | 次要内容、区块标题 |
| `--ink3` | #9b958c | 日期、辅助信息、空状态 |
| `--bg` | #fbf9f5 | 页面底色（暖纸白） |
| `--surface` | #fff | 卡片、输入框 |
| `--paper` | #fcf6ea | 只用于「今天」的卡片和回忆卡背面 |
| `--blue` | #3d6bfd | **只用于能点的东西**：主按钮、选中的 tab、悬停的链接 |

不用颜色表达状态。记忆默认就是“你说过的”，只有“推测”加一个虚线小标——例外才标出来。

## 间距

4 的倍数。页面左右 48，区块之间 44，列表行上下 12。

## 插画

只出现在三处：头部的窗边小景（随她的状态切换：醒着 / 在读 / 想你 / 睡觉，淡入淡出 200ms）、空状态、回忆卡片正面。不在区块标题旁边放插画。

插画统一为淡水彩、透明底、蓝白为主、点缀暖色，不画人物、不带文字，放在 `assets/`。

## 交互

- 修改、忘掉这类操作平时隐藏，鼠标悬停在那一行时才出现。
- 不常看的内容默认折叠：“3 条已经不成立”“再看 5 天”。
- 回忆卡片点一下翻面，背面是当时的原话。
